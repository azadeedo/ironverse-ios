# Ironverse

Personal offline-first training PWA for a specific garage gym (LSG GRK-110 rack,
barbell + curl bar + 100kg of plates, FID bench, jump rope). Progressive plans with
plate-aware loads, animated SVG exercise demos + muscle maps, live workout player,
advanced nutrition with adaptive-TDEE deficit detection, hydration/creatine reminders,
work-schedule-aware workout timing, cardio + jump-rope interval timers, full progress
tracking, backup/restore. All data on-device.
