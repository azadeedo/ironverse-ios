Back up your data

Your data lives only on your iPhone. Open More → Backup → Export backup and save the file to Files or iCloud Drive. Do this regularly, and always before changing phones.

Move from the Ironverse web app

  1. In the web app, open More → Backup → Export backup and save the file.
  2. Install Ironverse from the App Store. On the first screen tap "I already use Ironverse — restore a backup".
  3. Choose the file, check the summary and pick Merge. Your history, plans and settings come across. The web app keeps its own copy.

Replay the tour

More → Settings → Replay the app tour.

Reminders don't arrive

Allow notifications for Ironverse in iOS Settings → Notifications. Reminders are created on your phone, so they need no internet connection.
